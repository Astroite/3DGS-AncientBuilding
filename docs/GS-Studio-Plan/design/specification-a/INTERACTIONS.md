## 项目、实验、检查点与快照

| 对象 / 操作 | 用户可观察语义 |
| --- | --- |
| 保存项目 | 保存数据关联、当前配置、观察位置、检查点关联和已保存编辑版本；不暗示新增检查点 |
| 实验 | 一次确定输入与关键配置的训练；变化时新建实验，旧实验保留 |
| 保存检查点 | 保存实际可恢复的训练状态，成功后显示实际步数；不能凭“有文件”报成功 |
| 原始模型快照 | 某次训练成果的只读编辑来源，注明实验和步数 |
| 编辑版本 | 从快照派生，独立于活动训练，提交编辑后可另存 |
| 导出成果 | 从明确选定的原始快照或已保存编辑版本生成 PLY，单独报告导出结果 |

保存项目若遇到未另存的编辑内容，先提示保存该编辑版本或取消本次保存，不能默默丢弃。保存失败维持未保存标记。成功提示分别写“项目已保存”“检查点已保存至 N 步”“编辑版本 E-02 已保存”，不合并为一个含糊的“保存成功”。

## 主流程与导入

从 A-P01 新建或打开项目；拖入目录或分别指定 Images/COLMAP/Masks。目录只有引用，设计操作不修改输入。识别多模型时列表要求选择一个；每次改模型或目录均使旧检查结论失效。

A-P02 显示完整输入规模和逐项问题。缺图、坏图、命名歧义、遮罩错配、不支持相机、非法内参/位姿或未知的关键校验结果都不能静默略过。未匹配项显示在列表，必须处理或明确调整输入后重新检查。完整错误明细可按类型筛选；“定位文件”展示对应条目及完整路径，不依赖只在悬停出现的提示。

遮罩默认示例为白色保留、黑色忽略。点击反转后，极性文字和不会参与训练的覆盖区域同步改变；选择保存到项目配置中，并使相关导入摘要待重新确认。无 masks 目录时明确显示“未使用遮罩”，不报缺失错误；一旦提供目录，须检查关联与尺寸。遮罩忽略观测，不把遮挡部分训练为黑背景。

A-P03 的就绪仅指输入检查完成，实际开始前仍要检查 GPU 可用性、显存和输出目录。预设切换显示实际分辨率、步数、SH 与补偿。正式训练默认 SH 3、光度补偿开启；30,000 步、最长边 1746 px、检查点间隔 1,000 步为本稿模拟配置，不固化 D-10 的最终预算。快速预览明确标识用途；其最终默认预算留在既有训练配置评估任务中。

已有 226/30 分组按来源保留。来源不可靠或未知时显示说明，不能把猜测当作可信分组；具体分组策略仍由 D-06 定稿。点击相机可看图，点击图片可定位相机；改变观察视角不改变训练/验证归属。

## 训练状态与动作

详见 [A-S01](11-lifecycle-states.svg)。按钮禁用原因出现在按钮附近或常驻状态区，不能只通过 tooltip 解释。

| 状态 | 主要动作 | 可用操作与退出条件 |
| --- | --- | --- |
| 准备中 | 取消准备 | 看检查详情；未开始训练，不显示虚构损失或进度 |
| 等待资源 | 取消等待 | 看原因、等待时长；返回配置会取消当前等待；禁止强占其他任务 |
| 训练中 | 暂停训练 | 保存检查点、结束并保留、观察模型；修改关键配置走新实验 |
| 暂停中 | 等待暂停完成 | 禁止重复提交和提前继续；确认停止优化后才显示已暂停 |
| 已暂停 | 继续训练 | 可保存检查点、结束；恢复前重新确认必要条件 |
| 结束保存中 | 等待保存结果 | 看日志；应用内关闭入口暂不可用，不能声称能够阻止系统终止进程 |
| 已完成 | 编辑快照 | 可导出；标明达到目标或提前结束及实际步数 |
| 失败 | 查看原因 | 显示最后有效检查点和已有成果；修复、校验后才能恢复 |

“结束并保留”停止本次优化并保存有效成果，未收到保存成功结果前不能显示完成。暂停保存与关闭保存期间，只反映实际结果；程序异常中断后的恢复依据最后有效检查点。

进度显示当前/目标步数、损失、高斯数、速度、运行耗时和显存，剩余时间带“约/估算”。本稿 12,000 / 30,000、Loss 0.04821、高斯 1.84 M、42.0 步/秒、04:46 和约 07:09 全部为模拟，不是实测或目标性能。

## 观察与对照

A-P04 可以旋转、平移、缩放、自由漫游，切换相机、稀疏点、轴和网格，保存/恢复观察位置。预览清晰度和更新频率是显示设置，与训练图像分辨率及 SH 设置分开；查看器曝光也不改变训练补偿。

进入 A-P05 时保存当前自由观察位置，锁定选中输入相机。源图和渲染使用同一相机及相同可见区域，保持原始宽高比；缩放和平移默认同步且本版不提供单侧解除同步。切换相机重置到新图适配视图，不沿用上张图的局部裁切。单画面模式切换源图/渲染时保持该相机的缩放位置。

“返回自由视角”恢复进入前的观察位置；对照期间的画面平移是图像观察，不修改相机位姿。同步视角或渲染尚未就绪时显示“当前渲染更新中”，不得将上个相机画面标为本相机结果。点击辅助显示或比较切换不会暂停训练。

## 快照编辑与手柄

进入编辑先选择已有快照，或在存在有效训练成果时请求创建当前快照。快照未就绪不能开始编辑。身份条常驻“来源实验 / 快照 / 步数 / 编辑版本”，并显示活动训练状态。切换快照前处理当前未保存编辑；原始快照和其他版本保留。

| 动作 | 预览、提交与撤销 |
| --- | --- |
| 矩形选择 | 拖出屏幕矩形，松开形成选择并更新数量；Esc 取消尚未完成的矩形 |
| 反选 / 清空 | 针对当前编辑快照；未选中时删除禁用 |
| 穿透 | 关闭按最终可见性规则选取，开启包含遮挡后的候选；底层算法仍待 D-07 技术评估 |
| 删除 | 只删当前选中的编辑快照高斯；显示数量，一次操作对应一次撤销 |
| 裁剪 | 面/角点手柄和中心/尺寸输入同步更新待提交框；框内/框外切换同步预览影响 |
| 应用裁剪 | 应用前保持模型不变，确认后整体裁剪记一条撤销；取消或 Esc 丢弃待提交框调整 |
| 平移 / 旋转 / 统一缩放 | 选轴/平面/旋转环或中心缩放柄，拖动联动数值；松开形成一次模型变换撤销记录 |
| 数值变换 | 输入时预览合法值，Enter 或完成字段编辑确认一次；非法数值不提交，Esc 恢复编辑前值 |
| 朝上与地面 | 选择朝上轴或“以当前水平面设为地面”后显示待确认预览；应用一次记一条撤销 |

裁剪调整尚未应用时，手柄松开和数值确认记录一条框体调整撤销；该预览历史与模型编辑历史分开。取消裁剪清空这段预览历史，应用后在模型历史中记录一次完整裁剪，避免一次裁剪需要逐点撤销。全局撤销在裁剪预览中优先撤销框体调整，并标明“撤销框体调整”；退出预览后恢复模型历史。

平移/旋转提供世界和局部坐标；统一缩放只改变一个倍率，必须为正数，不提供各轴缩放或镜像。切换工具或坐标系时先结束或取消当前未提交手势，不能把一次操作拆进两个坐标系。选中轴与对应数值字段同时强调；Esc 取消当前手势，不回退已经提交的上一条操作。

撤销后执行新编辑清除当前版本的重做分支，保留已另存的版本。删除、裁剪和变换均支持撤销重做。保存后的最终编辑结果需能在项目重开和导出时一致呈现；跨进程完整撤销历史持久化不在此稿中承诺。方向相关颜色与高斯属性的正确变换是 E-03 的后续实现/验收要求，本设计不选择算法。

## 保存、关闭、恢复与导出

详见 [A-S02](12-save-recovery-states.svg)，错误示例均为模拟。

- 关闭时有未保存编辑：提供“保存后关闭 / 放弃未保存编辑并关闭 / 取消”。若活动训练仍在运行，先明确执行结束并保留或取消关闭；不能直接丢弃训练。保存失败留在项目并显示原因。
- 检查点保存：写入中显示处理中；成功才更新有效步数。保存失败保留旧检查点身份，例如 11,000 步，并给出重试或查看日志入口。
- OOM：显示失败原因和最后有效检查点，不自动降低训练分辨率、SH 或其他画质设置。同配置恢复须重新检查必要条件；更改关键配置转新实验。
- 检查点损坏：损坏记录标记为不可恢复，不删除其历史；有更早有效点时显示具体步数和回退差额，无有效点则禁用继续并提供新建实验。
- 源数据失联：保留原引用，选择候选新目录后校验图片、COLMAP、遮罩和已有分组。进行中禁用继续训练；取消不改原引用；失败展示差异；全部通过后确认采用新位置。
- 输入或关键配置变更：保留旧实验，展示变化摘要并新建实验。哪些字段属于关键配置由后续训练评估定稿，不把预览频率和显示曝光算作训练身份变化。
- A-P10 示例选择 11,000 步有效检查点；12,000 步损坏记录不能继续。源数据校验完成后启用恢复按钮，继续前再次显示恢复步数和实际配置。
- A-P09 导出必须选择明确原始或已保存编辑版本，包含 Gaussian PLY 的位置、颜色/SH、不透明度、尺度及旋转等必要属性。输出与源文件冲突或目标已存在时提示改名/另选路径，不默认覆盖。
- 导出中禁重复提交。失败保留模型，显示输出错误和重试入口；只有本次导出明确成功才显示完成和文件位置，并提供重新导入检查入口。是否能被独立查看器正确加载留待 AC-12 验收。

项目恢复界面不决定 D-05 的存储策略；不论外部引用还是被采用的自包含方式，都要清楚报告文件可用性与校验状态。

## 键盘与焦点

Tab / Shift+Tab 按页面视觉顺序遍历可操作控件；隐藏侧栏不参与焦点顺序。Enter 确认聚焦字段或按钮；有未提交编辑时优先处理该编辑。Esc 先取消当前手势/数值预览，再关闭浮层，不取消正在写入的保存任务。

Ctrl+S 对应保存项目；Ctrl+Z / Ctrl+Y 在模型编辑区对应撤销/重做，在文字输入中保留文字编辑含义。删除高斯要求焦点位于编辑视口或相应按钮，不在路径输入时响应删除模型。所有主要操作都有可见文字入口，不依赖快捷键。
