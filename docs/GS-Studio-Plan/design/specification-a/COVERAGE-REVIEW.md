## 逐场景设计走查

| 场景 | 设计预期 | 覆盖结论 |
| --- | --- | --- |
| 首次创建并导入 | 空项目→选择目录/模型→配对摘要→确认配置→准备训练 | A-P01～04 + A-S01，静态覆盖 |
| 输入异常 | 显示完整输入及问题类型，定位文件，禁止静默丢图 | A-P02 展示遮罩尺寸错误；其他类型由交互文档定义 |
| 遮罩反转 | 极性文字和忽略覆盖同步更新；重新确认摘要 | 正反行为有文档；主稿展示白色保留状态 |
| 等待取消 | 明确等待原因、取消入口，不强占资源 | A-S01，静态覆盖 |
| 暂停与保存 | 暂停请求→暂停中→已暂停；检查点保存单独确认 | A-S01/S02，静态覆盖 |
| 异常恢复 | 损坏点不可用；显示较早有效步数和回退差额 | A-P10 + A-S02，静态覆盖 |
| 源数据搬移 | 重新定位→校验→通过后确认新路径→继续 | A-P10 展示校验中；成功/失败行为由文档定义 |
| 大尺寸对照 | 相机锁定、等大画面、比例保持、同步和返回 | A-P05，静态覆盖 |
| 最小窗口对照 | 收起侧栏，源图/渲染同位置切换，关键动作可见 | A-R06，静态覆盖 |
| 选择、裁剪、变换 | 快照身份固定，手柄和数字同步、提交前可取消 | A-P06～08；完整手势由文档定义 |
| 撤销与重做 | 一次已提交编辑对应一次撤销；预览历史有明确边界 | A-P06～08 + 交互说明，静态覆盖 |
| 保存后导出 | 选择原始或已保存编辑版本，明确属性与输出结果 | A-P09 + A-S02，静态覆盖 |

## 评审结果及未覆盖边界

- 用户已明确确认DEV-04完整设计，记录为设计评审通过、M2完成；以下覆盖边界保留，AC-13正式应用验收未完成。
- 小窗口稿覆盖训练和对照；导入、编辑、导出与恢复的小窗口行为有规则，未逐页另制尺寸稿。
- 各异常和生命周期以状态板及交互说明表达，未为每种状态制作独立完整工作台。
- 旋转为完整变换页的主状态；平移/统一缩放有手柄示例与行为规则，未另制独立全页。
- 深层高级参数的最终字段、训练预设预算、分组策略、项目存储方案、非穿透拾取算法仍属于已登记的后续技术/产品任务。本次没有建立 API 或文件 schema。
- 仅完成文件、XML、尺寸和链接等静态核对；没有截图渲染、真实 DPI、应用操作、CPU/GPU 测试、训练、性能或画质验证。
