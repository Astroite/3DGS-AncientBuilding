# 本目录交接规则

先读 README、status/BASELINE.md、planning/BACKLOG.md，再处理具体任务。

## 当前授权边界

- 用户明确要求不运行 CPU/GPU 测试、不干扰其他会话。不得启动单测、集成测试、基准、训练、应用验收程序、GPU 轮询或等待任务。历史命令和路线图不是执行授权。
- 不以 GPU 空闲、测试很短或使用合成数据作为例外。只有用户后续明确要求恢复相应验证，才更新此约束。
- 此目录用于文档、需求和静态设计规划。不要为建立目录初始化依赖、创建后台服务、安装 skill/plugin，或移动 APP/Data。
- 保留工作区未提交更改。若后续需要修改 APP，先读 APP/AGENTS.md 与 APP/docs/CURRENT-WORKFLOW.md，并遵循工作区 CodeGraph 规则。
- 不自行启动子 Agent、其他会话或并行任务；文档中的角色分工不是委派授权。

## 产品和证据规则

- 本目录的 2026-09-13 首版范围是导入、训练可视化、基础编辑、保存与 PLY 导出；2026-09-22 起现行全流程 GUI 范围以 APP 两份路线图为准。P1 不自动升级为首版。
- 正式 UI 前先完成三方向静态探索，并由用户选择方向。原型界面不能作为视觉验收通过的证据。
- 不展开本轮未要求的架构设计。待定技术项应进入决策清单，不能暗中沿用原型选择。
- 不修改原数据、输入哈希、训练/验证分组或 QA 状态来让结果通过。
- 区分官方文档声明、已读本地资料、历史运行记录、当前推断及尚未验证项。保留来源和日期。
- 历史测试通过不覆盖后续改动；GPU 等待超时不得记为 GPU 测试通过。

## 更新方式

需求保留稳定编号；任务注明依赖、交付物和验收 ID；完成时记录对应文件或证据。仅做文档时可检查文件和链接，不启动应用测试。重要范围或默认值变化同时更新 CHANGELOG.md。
