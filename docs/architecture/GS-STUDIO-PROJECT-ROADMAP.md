# GS-Studio 项目路线图

更新：2026-10-08。状态：固定 CUDA 环境、合成训练恢复、真实 DJI 遮罩及首个 Windows 目录包已获得分层证据；人工遮罩审核、真实重建/画质和完整产品验收尚未完成。本文件是阶段与验收状态的现行入口；工程拆分见 [工程路线图](GS-STUDIO-ENGINEERING-ROADMAP.md)。当前实际操作仍以 [Windows 工作手册](../user/CURRENT-WORKFLOW.md)为准。

## 已确认方向与现状

- GSStudio 保留仓库和目录，产品名统一为 **GS-Studio**。日常项目操作最终从 GUI 完成；`gsstudio` CLI 保留给脚本、恢复和底层操作，业务规则由两种入口共用。
- GUI 覆盖地点、场景、Capture、Run、重建、QA、训练、模型编辑与交付。首次安装、底层诊断和应急恢复仍可使用脚本或 CLI。
- 正式主线沿用现有 Python/gsstudio/gsplat 基础。**新 GUI 实验预选 gsplat**，并可明确选择 Postshot；现行 CLI `train --segment` 的 Postshot 默认与 Run 配置不因路线图而改变。旧包名和旧命令无兼容入口；现行 Run 清单 schema 与 Data 布局保持不变。
- [A 深色专业工作台](../archive/GS-Studio-Plan/design/specification-a/README.md)已通过静态设计评审，覆盖重建后工作台；采集、Run、重建和 QA 的 GUI 流程设计仍需补齐。GSStudio 的 Tk Studio 是功能原型，不是正式 UI 或运行验收结论。
- [GS-Studio-Plan 历史资料](../archive/GS-Studio-Plan/README.md)保留 PRD、需求编号、设计稿、技术评估与历史证据。其 2026-09-13 的下游工具范围和 LichtFeld 主推荐均作为当时记录；本文件及[工程路线图](GS-STUDIO-ENGINEERING-ROADMAP.md)承载 2026-09-22 后的新方向。

## 需求与验收追踪

旧需求 I（导入）、T（训练）、V（查看）、E（编辑）、O（交付）、UI 和 NFR 编号继续有效于其原有功能。新增上游需求仅作为路线图编号，实施前在统一需求清单中展开，不修改数据或清单格式。

| 新编号 | GUI 目标 | 计划验收 |
| --- | --- | --- |
| C-01 | 浏览并创建地点、场景、Capture；显示已存在对象并拒绝覆盖 | AC-17 |
| C-02 | 从 GUI 探测输入、展示来源和前置条件，再执行现行 ingest | AC-17 |
| R-01 | 创建新 Run、呈现配置与身份、启动或恢复 preprocess | AC-18 |
| R-02 | 遮罩预览、人工门禁、重建与一次受限 repair 的状态和操作 | AC-18 |
| Q-01 | 查看分段适用性与路线覆盖，按实际选中结果选择可训练分段 | AC-19 |
| Q-02 | 展示 Run/训练证据与清理预览，确认后按现行白名单执行 | AC-19 |
| G-01 | GUI 项目浏览、依赖检查、日志、等待/失败/恢复与当前动作提示 | AC-20 |

AC-17：创建和探测流程保持原片只读、不覆盖已有清单；输入异常可定位。AC-18：GUI 只允许满足现行阶段前置条件的操作，状态、锁、输入哈希和恢复身份与 Run 清单一致。AC-19：分段可训练与全路线覆盖分别显示；清理先预览，执行仍受 Run 锁、白名单及消费者校验约束。AC-20：项目浏览和错误信息可定位到实际清单、日志及结果；等待、失败或仅有输出文件均不显示为成功。两段 DJI 的 CLI Capture 登记、探测和 ingest 为 AC-17 的部分证据，不代表 GUI、Run 或其余 AC 项通过。

## 本轮边界

本轮沿用隔离测试项目，只读引用 `Data/Test` 的 DJI 视频；短段 5 秒 Run 已完成预处理与真实遮罩，停在原配置要求的人工门禁。两环境固定 CUDA 诊断和合成训练通过，最终 101 项 CPU/Qt 检查通过；已生成四入口 Windows 候选包。具体身份、数值及尚未完成的验收见 [10 月记录](../development/VALIDATION-2026-10-08.md)。QA 判定规则与 CLI 默认后端（Postshot Splat ADC）未变；未自动启动全量训练。[旧基线](../archive/GS-Studio-Plan/status/BASELINE.md)仅是 2026-09-13 历史证据。
