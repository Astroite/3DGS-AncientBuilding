# D-04：采用 A 深色专业工作台

- 日期：2026-09-13
- 状态：已接受
- 决定者与依据：用户在三方向静态稿交付后表示“感觉A就可以了”。
- 关联需求和任务：UI-01～04、V-03；DEV-02、DEV-03、DEV-04；AC-13。
- 替代的既有决定：无；关闭 D-04 方向待决事项。

## 要解决的问题

从同内容的三套静态方案中确定正式 UI 的视觉和布局基础，为后续页面与组件细化提供统一方向。

## 可行选项

| 选项 | 主要特点 | 取舍 |
| --- | --- | --- |
| A 深色专业工作台 | 石墨灰、青绿强调；左侧素材、中央大视口、右侧检查器、底部训练状态 | 参数与素材可同时查看；需控制面板密度并补齐大尺寸对照状态 |
| B 极简创作工具 | 浅色、蓝色强调；按准备/训练/编辑/导出组织 | 步骤清楚；跨阶段操作需要切换 |
| C 影像检查工作台 | 深色、琥珀色诊断提示；源图与渲染等大并排 | 精细对照直接；单个视口面积较小 |

依据为[静态稿与比较表](../../design/deliverables/COMPARISON.md)，没有运行性能、开发成本或技术兼容性评测。

## 决定与理由

采用 [A 深色专业工作台](../../design/deliverables/DIRECTION-A.md)作为正式设计基线，涵盖主工作台与导入检查页。选择依据是用户明确认可 A；未提供更细的偏好理由，不代为补写。

保留 A 的石墨灰与青绿配色、中央大视口和可折叠侧栏组织。B/C 保存为探索档案；本次未要求融合其布局。现有两张 A 稿是后续细化的基础，不能视为所有页面与交互细节定稿。

## 后续影响

DEV-02 交付完成，DEV-03 方向评审完成，M1 风格探索完成。方向决定时 DEV-04 待开始，现已获用户[完整设计评审通过、M2完成](../../design/specification-a/README.md)。细化重点如下；这些是已有需求的设计工作，不是用户新增反馈：

1. 完整状态：空项目、导入阻断、准备/等待、训练、暂停、失败、恢复、编辑、导出与项目重开。
2. 展开源图与渲染的大尺寸同视角对照，明确同步缩放/平移、当前相机和返回自由视角的行为，满足 V-03。
3. 细化 1280×800 侧栏收缩、1920×1080 布局及 100%/150% 缩放规则，保障主要操作和错误原因可读。
4. 明确项目保存、检查点、暂停/结束、编辑快照与导出的操作状态；补齐遮罩、选区、裁剪、变换及撤销反馈。
5. 统一组件、字体、间距和键盘焦点等状态规范，保留高级参数渐进展开。

UI-01 的三方向比较与用户选择已完成；完整规范亦已获用户认可，AC-13正式UI验收仍待后续。本决定不选择技术架构，也不解除 D-02 的 CPU/GPU 测试与运行验证暂停约束。
