## 风险登记

| 风险 | 影响 | 处理方式 | 状态 |
| --- | --- | --- | --- |
| R-01 原型被误当成成品 | 遗漏真实训练、画质或兼容缺陷 | 保留“有原型/未验收”状态；证据关联具体版本 | 持续管理 |
| R-02 复用结论未经运行验收 | 选定主线仍可能在画质、恢复或资源上暴露缺陷 | 按 D-03 主线实施，未来获得授权后对目标版本验收；保留技术评估作为参考 | 主线已选择，运行验证待授权 |
| R-03 图片/相机/遮罩错配 | 训练失败或生成难以定位的画质问题 | 导入阻断、明示极性、保护分组与输入身份 | 有原型，待验收 |
| R-04 新 UI 只换皮 | 用户仍认为拥挤和难用 | 三套不同信息组织方案，先静态选型再正式实现 | A已选定；DEV-04设计评审通过，应用未验收 |
| R-05 UI 与训练争抢资源 | 卡顿、显存不足、影响其他任务 | 未来评估资源协作；当前完全暂停运行验证 | 当前限制生效 |
| R-06 恢复/编辑混淆 | 修改训练状态、丢失原始成果 | 独立快照、明确项目与检查点语义、版本校验 | 有原型，待验收 |
| R-07 旋转后方向相关颜色错误 | 导出外观与预览不一致 | 高斯方向与 SH 一致处理，后续独立查看器核验 | 历史局部测试，不代表最终通过 |
| R-08 大数据复制与内存占用 | 项目体积和导入耗时不可接受 | DEV-05已定位prepare/另存全量复制与预览上传；D-05/D-08定义策略和目标 | 静态发现已登记，资源成本未知 |
| R-09 历史测试覆盖被夸大 | 后续改动没有有效验证 | 历史记录独立保存，最新实现保持未验收 | 已明确 |

DEV-05新增关注：上游默认重分组/降级输入、标准PLY与额外外观补偿差异、完整续训状态及Windows工具链跨度。证据与切换条件见[技术评估](../research/technical-evaluation/README.md)。D-03 的选型已由用户确定；D-05/D-06/D-07 仍待对应阶段决策。
