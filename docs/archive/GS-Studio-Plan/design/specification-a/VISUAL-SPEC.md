## 视觉基线

延续 A 的石墨灰、青绿强调和三栏工作台。大视口为视觉中心，素材位于左侧，当前任务检查器位于右侧，训练指标位于底部。当前页面和状态由标题、标签与按钮文字共同表达；不只改变颜色。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 应用底色 | #121719 | 外围、独立分组之间 |
| 面板底色 | #1B2225 | 侧栏、操作区、卡片 |
| 次级表面 | #263135 | 次按钮与控件 |
| 视图底色 | #101516 | 图片保持比例后的留边 |
| 边界 | #354247 | 面板、输入和分隔 |
| 主文字 | #EAF1F0 | 标题、可执行动作、主数值 |
| 次文字 | #A5B4B6 | 标签、单位、解释 |
| 强调 | #77D6C3 | 主操作、选中轴、选中图、焦点 |
| 强调底色 / 强调上文字 | #233D39 / #102A24 | 身份条、选中表面 / 实底主按钮文字 |
| 提醒 | #EDC17C | 等待、未完成校验、阻断说明 |
| 错误 | #FAADB1 | 失败、非法值、问题定位 |
| Z 轴辅助 | #8DAFF7 | 变换 Z 轴，始终附轴名 |

状态图形使用内嵌 SVG 线条、方框及简单符号，并附文字。成功使用“✓ + 结果”，异常使用“! + 原因”，运行使用“训练中”等状态名称。轴色不兼作错误判断；编辑轴标签明确为 X/Y/Z。

## 字体与尺寸

字体回退顺序为 Segoe UI、Microsoft YaHei UI、Microsoft YaHei、sans-serif；不加载网络字体。稿中以文字保留中文内容，未转曲；最终字形受阅读环境的系统字体影响。

| 层级 | 逻辑字号 | 字重 / 用途 |
| --- | --- | --- |
| 页面标题 | 32 | 600 |
| 面板标题 | 20～21 | 600 |
| 主要进度 | 26～34 | 600，目标步数另用次级文字 |
| 正文与操作 | 17～18 | 400～600 |
| 标签、辅助说明 | 15～16 | 400 |
| 图片文件名与设计页脚 | 13～14 | 400；不用于主操作 |

基本间距 8；组内常用 12/16，面板内边距 24，区域间隔 24/32。常规按钮 42 高，主要按钮 46～48 高，数值输入 44 高，路径输入 52 高。圆角通常 7～8；图片和内部预览区域用 4～5。键盘焦点为 2 px 强调外框、与控件间隔 2 px。禁用保留边界和可读标签，并在相邻位置给出原因。

[基础组件板](13-basic-components.svg)规定默认、悬停、焦点、选中、禁用、错误、处理中状态。焦点仅表示键盘目标，选中表示当前图片、选项或工具，二者可同时出现。

## 标准工作台

1920×1080 / 100% 以 SVG 画布为应用内容设计范围；原生窗口装饰与最终实现尺寸换算留在框架选型后处理。

- 顶部 72 高：项目身份、设计示意、保存项目、导出与项目菜单。无模型时导出禁用。
- 左素材栏占 284；内容面板从 x=304 开始。常驻列表不承担训练配置。
- 右侧分配 324 宽，含边距；主训练稿的检查器卡片为 x=1600、宽 296。
- 中部主画布容器为 1272×690；图片或矢量示意在容器内等比适配。容器尺寸不等于实际场景图像像素。
- 训练操作在右侧，损失、数量、显存、速度和耗时集中在底部。
- 高级训练参数折叠；训练配置、预览清晰度/频率和查看器曝光分别分组。

本交付的街景沿用 DEV-02 的原创 1200×720 矢量符号，以 meet 等比显示，不拉伸也不为了填满画布裁去边缘。1746 px 和示例源图/遮罩尺寸属于输入说明，矢量街景不表示真实照片的像素、比例或画质。在正式应用中，对照应按实际源图尺寸和宽高比绘制。

## 对照布局

[标准对照](05-compare.svg)保留左素材栏，收起右检查器，两个等大画面容器分别为 756×536。源图与渲染各自显示清晰标题，同一相机、同一可见区域、默认同步缩放和平移。

对照可用宽度扣除内边距和两图间隔后，若每图至少有 480 逻辑像素宽度，采用并排；否则切换为同位置的“输入源图 / 当前渲染”按钮。切换仅改变显示内容，保留缩放和平移，不以缩小文字维持双图。

## 收缩与缩放

布局断点按可用逻辑宽度选择，字体和控件逻辑尺寸保持一致。

| 可用逻辑宽度 | 布局 |
| --- | --- |
| ≥1600 | 完整三栏；对照时收起右检查器 |
| 1200～1599 | 素材栏收为 72；右检查器列占 280，含边距；对照收起该列 |
| <1200 | 两侧变为抽屉；顶部保留素材、检查器和观察工具入口 |

紧凑状态将详细曲线与次级指标放入详情；暂停、保存检查点、进度和错误状态保持可见。最小窗口的结束保留位于“训练详情”中，底部不堆放所有动作。一次只展开一个侧栏抽屉，Esc 关闭并返回触发入口。

| 物理画布与缩放 | SVG 逻辑 viewBox | 稿件 |
| --- | --- | --- |
| 1280×800 / 100% | 1280×800 | A-R01 / A-R02 |
| 1920×1080 / 150% | 1280×720 | A-R03 / A-R04 |
| 1280×800 / 150% | 853.333333×533.333333 | A-R05 / A-R06 |

导入页在逻辑宽度小于 1600 时改为“输入→摘要与预览→问题”的上下顺序。内容独立滚动，底部操作固定；路径显示开头和文件夹末尾，提供完整路径入口。无横向空间时次要按钮进入有文字的菜单。不可通过同比缩小全文来适配窗口。

本阶段只交付上述布局推演。100% / 150% 实际字体、系统标题栏、点击区域及应用 DPI 行为尚未运行验证。

## 编辑控件与反馈

- 矩形选择以边框与半透明填充显示，已选高斯有高亮且显示计数；穿透状态有明确开关和说明。
- 裁剪框用可见边实线、遮挡边虚线、角点方形手柄；将移除部分以半透明覆盖配合“将移除”说明。框内/框外是互斥保留选项。
- 平移提供轴与平面手柄；旋转提供轴向环；统一缩放提供中心手柄，不提供各轴独立缩放。
- 选中轴增粗并附“已选”，对应数值字段加描边；原始与编辑模型身份一直可见。
- 世界/局部坐标用于平移和旋转，统一缩放不因坐标选择改变含义。朝上方向和地面调整使用带预览的明确操作，确认后才提交。
- 图中旋转为主状态，并以小示例补充平移和统一缩放手柄。完整交互规则见交互文档；手柄不是底层求交算法的实现承诺。
