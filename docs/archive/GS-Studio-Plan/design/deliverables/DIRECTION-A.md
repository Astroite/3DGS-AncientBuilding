## 布局意图

适合连续检查模型、频繁切换图片和调整训练配置的操作者。训练状态始终可见，空间观察占据中心；工具按素材、视口、训练三种职责分开。

主工作台：顶部 72 px 为项目操作；左侧 284 px 为图片与数据摘要，右侧 324 px 为训练检查器。中间主画面 1272×738；训练资源集中在视口下方，而不是分散为一整屏仪表盘。当前源图在右侧提供快速参考，主视口上方的“源图对照”用于后续打开大尺寸对照。

导入页：左侧输入目录，右侧检查摘要、空间预览和问题列表。统一的底部操作区显示阻断原因与下一步；存在问题时禁用开始训练，不把错误藏在通知里。

## 字体、间距和组件

- 字体：`Segoe UI → Microsoft YaHei UI → Microsoft YaHei → sans-serif`；无网络字体。中文按系统可用字体回退。
- 字级：导入页标题 32，面板标题 20–21，正文 17–18，辅助信息 14–16；主要指标 27–30。数字和单位分层显示。
- 基础间距 8 px；常用组内 12/16，面板留白 20/24，页面区域间距 24/32。工具栏保持紧凑，但不缩小主要按钮文字。
- 按钮：次级 42 px，主要训练操作 46 px；圆角 7 px。“暂停训练”为当前阶段主操作，“结束保留”次级，“保存检查点”独立成行。
- 输入：52 px 高，右侧独立选择按钮；底色和边框明确，不使用空白占位代替字段名。
- 选中：图片有青绿描边与加重文件名；列表用底色和“尺寸错误”等文字同时表示状态。
- 焦点规则：后续正式实现使用 2 px 强调色外框与 2 px 间隔；当前两张稿没有穷举键盘焦点状态。

组件示例位置：工作台右侧暂停/结束按钮、左侧 frame_0042 图片；导入页路径字段、问题行和底部禁用开始按钮。

## 1280×800 收缩规则

1. 顶部项目名称截断，完整路径放入可展开详情；保存/导出保留文字入口。
2. 图片栏折叠到 72 px 导航轨道，需要时展开；训练检查器为 280 px。
3. 源图对照展开时暂时收起训练检查器，以同尺寸两视图呈现；不能维持大侧栏同时把对照压成小图。
4. 资源区改为两行摘要，损失曲线按需展开；暂停、继续和错误状态保持可见。
5. 导入页改为上下组织，底部保留操作区；内容区滚动，按钮不随列表消失。

150% 显示缩放优先采用同样的折叠策略，不能直接按比例压小字体。上述为设计规则，未运行 DPI 检查。

## 取舍与后续评审

优势：素材和训练参数可同时查看，视口面积较大，接近专业桌面工具的日常操作方式。

代价：初次使用的信息量高于 B；此稿的源图只是快速参考，正式同视角对照仍需在 DEV-04 展开大视图状态。三维编辑入口已示意，完整选区/裁剪状态不属于本次两页交付。

评审重点：用户是否需要参数常驻，以及图片栏是否值得长期占用宽度。不能从稿件推断真实帧率、响应速度或训练效果。
