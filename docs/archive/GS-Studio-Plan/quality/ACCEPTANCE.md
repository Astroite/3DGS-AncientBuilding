# 验收计划与证据规则

> 本文 AC-01～16 是 2026-09-13 下游功能的验收计划；全流程 GUI 增补的 AC-17～20 见 [APP 项目路线图](../../../architecture/GS-STUDIO-PROJECT-ROADMAP.md)。所有运行场景仍待用户明确恢复相应验证。

**当前仅编写验收计划，不运行任何测试或应用验证。** 下列步骤供未来用户明确恢复相应验证后执行；不提供自动启动脚本，不轮询资源。

## 功能与设计验收场景

| ID | 条件与操作 | 预期结果 | 需求 |
| --- | --- | --- | --- |
| AC-01 正常导入 | 给定有效 BIN/TXT 与 JPG/PNG，分别拖入和选择目录 | 可识别模型，图片/相机/点统计准确，原文件未变 | I-01～03 |
| AC-02 输入异常 | 分别给缺图、坏图、同名歧义、多模型、非法位姿/内参、不支持相机；含中文/空格/子目录 | 错误可定位；多模型要求选择；不静默丢数据或启动不合法训练 | I-02～05、NFR-02 |
| AC-03 导入预览 | 导入后切换图片、点击相机、开关辅助显示、恢复观察位置 | 双向定位一致，稀疏点和朝向合理，显示操作不修改输入 | I-06、V-04 |
| AC-04 遮罩与分组 | 使用已知黑白遮罩、错误尺寸/极性、已有训练验证分组 | 覆盖显示与忽略语义相同；异常阻断；已知分组不泄漏；曝光补偿不改变掩膜 | I-07、T-03、NFR-02 |
| AC-05 外部位姿直训 | 使用合格共享包或外部模型，确认配置后启动 | 不重新 SfM；实际输入、尺寸、步数、SH、补偿、日志和输出身份可追踪 | T-01～03、O-03 |
| AC-06 生命周期 | 在准备、等待、训练、暂停及提前结束之间操作 | 状态和可用按钮准确；结束保存有效成果；估算时间有标签；未训练不能显示完成 | T-04、V-02、O-03 |
| AC-07 恢复一致性 | 手动/自动保存后关闭重开；另设输入/配置变更案例 | 同身份恢复到有效检查点；更改关键条件拒绝原地恢复并引导新实验；不伪造成功 | T-05、O-03、NFR-02/06 |
| AC-08 资源与失败 | 在隔离环境模拟 GPU 忙、CUDA 不可用、OOM、输出不可写、检查点损坏 | 等待可取消；错误明确；保护最后有效状态；不静默降质量或干扰其他任务 | T-06、NFR-03 |
| AC-09 实时查看 | 训练中移动视角，切换相机、对照源图、缩放并调整预览质量 | 真实模型持续更新；同视角图像保持对应；训练配置不随预览参数改变 | V-01～05 |
| AC-10 基础编辑 | 矩形/反选/穿透、删除、裁剪、变换、撤销重做 | 高亮与数量一致；预览与提交一致；方向/SH 正确；活动训练和原始快照不被修改 | E-01～04 |
| AC-11 项目重开与搬移 | 保存视角、编辑历史、数据引用、检查点；按 D-05 的策略移动数据/项目 | 可重新定位并校验或按明确采用的自包含策略恢复；状态和编辑一致，错误不被掩盖 | O-01/03、E-04、NFR-02/06 |
| AC-12 导出互操作 | 导出原始与编辑 PLY，内部回读并在选定独立查看器加载 | 必要属性与 SH 保留；数量、方向、颜色与裁剪一致；源文件未被覆盖 | O-02/03、E-03、NFR-06 |
| AC-13 UI | 先静态比较三方向；以后对正式 UI 检查关键状态和窗口/缩放尺寸 | 有用户方向选择；规范一致；可读且视口优先；对照区足够；没有隐藏关键操作 | UI-01～04、T-02、V-03 |
| AC-14 本地离线 | 后续在离线环境使用核心链路 | 不依赖 Postshot 授权、云服务、账户或 CDN | NFR-01 |

AC-08 不应通过占用生产 GPU 或故意使其他会话失败来制造异常；未来测试隔离策略在恢复验证前明确。

## 性能和画质验收

### AC-15 性能

先在 D-08 固定硬件、驱动、软件版本、模型规模、图片数/分辨率和预览分辨率，再记录：

- 导入耗时、首个可见预览耗时和交互响应情况。
- 训练速度、累计与本次运行时间、预览开启带来的成本。
- 峰值内存/显存、模型数量、项目与 PLY 体积。
- 不同规模的失败模式和可恢复状态。

目前没有通过的性能预算。禁止用单个小合成模型推导百万级场景指标。

### AC-16 画质

代表素材至少覆盖街景和室内检查需求；正式选样记录在 D-08。与已有 Postshot 成果比较时固定输入分组、相机视角、显示曝光/颜色设置和已知训练预算差异。

分别检查细节、人物残留、漂浮点、高亮与新视角表现；记录 PSNR/SSIM/LPIPS 等指标时说明有效区域及验证划分。指标和人工意见不能相互替代；未命中的视角或尚无对照模型应明确写出。

## 证据与完成条件

每条 AC 记录：日期、代码版本/未提交差异标识、输入身份、设置、预期、实际、结论、截图/日志/模型位置、限制和执行授权上下文。可选结果为通过、失败、未执行、阻断；“阻断”不等于通过。

发布前需要 P0 需求对应的有效证据、用户认可的 UI、具体模型的人工画质结论及已知问题清单。原型存在、窗口能打开、短训练完成、退出码为零都不能独立满足首版验收。

历史检查仅作为基线参考，见 [BASELINE](../status/BASELINE.md)。本轮没有新增运行验收结果。
