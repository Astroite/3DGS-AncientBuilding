# 首版需求清单

> **历史下游需求基线。** I/T/V/E/O、UI、NFR 的原编号继续用于相应功能；新增 C/R/Q/G 与 AC-17～20、现行阶段见 [APP 项目路线图](../../../architecture/GS-STUDIO-PROJECT-ROADMAP.md)。表中“P0”指 2026-09-13 的下游首版，不表示全流程 GUI 已实现。

所有下列条目均为 P0。表中是目标完成标准，不是当前完成状态。实现与证据见 [基线](../status/BASELINE.md)，任务见 [Backlog](../planning/BACKLOG.md)，AC 编号见 [验收计划](../quality/ACCEPTANCE.md)。

## 数据导入

| ID | 需求 | 可观察完成标准 | 验收 |
| --- | --- | --- | --- |
| I-01 | 可视化导入 | 拖入根目录或分别选择 images/COLMAP；开始前有导入摘要 | AC-01 |
| I-02 | COLMAP 兼容 | 支持 cameras/images/points3D 的 BIN/TXT，识别 colmap、sparse/0；多模型明确选一个，不混合 | AC-01、02 |
| I-03 | 图片兼容 | JPG/PNG、中文路径、空格和子目录；源文件不覆盖 | AC-01、02 |
| I-04 | 对应关系检查 | 展示总图数、匹配相机数、训练图数和点数；列出缺图、坏图、未匹配项及命名歧义 | AC-02 |
| I-05 | 相机检查 | 核验模型、尺寸、内参、位姿；不支持的模型阻断；提示图像与畸变参数必须匹配，不宣称自动识别所有错误 | AC-02 |
| I-06 | 导入后预览 | 训练前显示稀疏点、相机位置/朝向；图片和相机双向定位 | AC-03 |
| I-07 | 遮罩 | 可选 masks、逐图对应与尺寸检查、覆盖预览、黑白反转；只忽略遮挡区域的观测 | AC-04 |

## 训练配置与控制

| ID | 需求 | 可观察完成标准 | 验收 |
| --- | --- | --- | --- |
| T-01 | 外部重建直训 | 使用导入位姿与稀疏点，不重新匹配或求解相机 | AC-05 |
| T-02 | 简明配置 | 快速预览/正式训练两档；展示实际分辨率、步数、SH 和补偿；高级参数折叠并解释影响 | AC-05、13 |
| T-03 | 光度补偿 | 曝光/白平衡补偿开关；与查看器显示曝光概念分开 | AC-04、05 |
| T-04 | 生命周期 | 开始、暂停、继续、提前结束保留；准备、等待、训练、暂停、完成、失败状态明确 | AC-06 |
| T-05 | 检查点恢复 | 自动和手动保存；关闭重开可继续；输入或关键配置变化创建新实验 | AC-07 |
| T-06 | 资源与失败 | 开始前检查 GPU、可用显存、输出目录；运行显示资源和错误；OOM 保留有效检查点，不静默降画质 | AC-08 |

## 基础编辑与交付

| ID | 需求 | 可观察完成标准 | 验收 |
| --- | --- | --- | --- |
| E-01 | 选区清理 | 矩形选择、反选、清空、删除、高亮、数量和穿透开关；拾取语义明确 | AC-10 |
| E-02 | 三维裁剪 | 框体可调整，支持保留框内/外；提交前可视化预览影响 | AC-10 |
| E-03 | 场景调整 | 整体平移、旋转、统一缩放、地面/朝上方向调整；保持高斯与方向相关颜色的一致性 | AC-10、12 |
| E-04 | 撤销与保护 | 删除/裁剪/变换可撤销重做；保留未编辑训练成果；编辑独立快照，不改变活动训练状态 | AC-10、11 |
| O-01 | 项目保存 | 保存数据引用、配置、检查点关联、视角与编辑结果；重开恢复；源数据移动可重新定位并校验 | AC-11 |
| O-02 | 模型导出 | Gaussian PLY 含必要属性与 SH；原始/编辑结果均可导出；可重新导入检查 | AC-12 |
| O-03 | 可追溯 | 记录实际输入、配置、状态、日志和输出位置；文件存在不能直接标记成功 | AC-05～08、11、12 |

O-01 原始要求保留。原型采用自包含数据副本，不代表已经实现外部引用重新定位；是否将其作为正式替代方案，必须在 D-05 中记录决定，不隐式删掉原需求。

## UI 与非功能要求

| ID | 要求 | 可观察完成标准 | 验收 |
| --- | --- | --- | --- |
| UI-01 | 风格探索 | 同内容的三套静态方向，具有不同布局与信息密度，不仅换主题色 | AC-13 |
| UI-02 | 设计规范 | 方向选定后统一字体、色彩、间距、组件、图标及状态规范 | AC-13 |
| UI-03 | 操作层级 | 视口优先、按任务组织工具；项目保存/检查点/导出等概念和按钮清晰区分 | AC-13 |
| UI-04 | 尺寸与可读性 | 中文与长路径可读；设计覆盖 1280×800、1920×1080、100%/150% 缩放；关键状态不只靠颜色 | AC-13 |
| NFR-01 | 本地工作 | 核心流程离线、无需 Postshot 许可，不依赖账户或远程数据服务 | AC-14 |
| NFR-02 | 完整性 | 原始输入只读；哈希与训练/验证分组不被静默变更；现有 QA 不被绕过 | AC-02、04、07、11 |
| NFR-03 | 资源协作 | 与工作区 GPU 使用规则一致；等待可取消；不干扰其他会话 | AC-08 |
| NFR-04 | 性能透明 | 后续在指定硬件/场景记录首个预览耗时、帧率、训练速度、内存/显存；阈值未确认前不得声称达标 | AC-15 |
| NFR-05 | 质量独立 | 功能、数值指标、人工画质分别记录；不因短测通过宣称画质通过 | AC-16 |
| NFR-06 | 恢复一致性 | 明确支持版本；不兼容输入/项目给出说明；恢复与导出记录关联到具体模型身份 | AC-07、11、12 |

需求和执行权限是两件事：存在 AC 编号不授权现在运行相应测试。
