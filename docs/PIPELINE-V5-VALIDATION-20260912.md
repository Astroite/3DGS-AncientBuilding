## Windows 原生训练验证

1. 合成 CUDA 前向、反向、保存恢复和 PLY 回读通过。中途从第 2 步检查点恢复，与不中断训练的最大渲染差异约为 `7.45e-9`。
2. 1000 步 ADC 测试实际把 100 个高斯增密到 355 个，并成功保存和导出。
3. 盐官首轮已通过 QA 的约 15 秒分段完成了 **1746 原始投影分辨率的 100 步诊断训练**，使用 283,244 个初始化点；恢复、标准 PLY、验证渲染和角度扫描均完成。

真实数据诊断在 `.repair-runs/pipeline-v5-20260912/real-data-smoke`。其 PSNR 约 18.98、SSIM 约 0.63、LPIPS 约 0.69，仅用于确认链路；图像仍明显模糊。100 步没有完成 ADC 或 SH 渐进训练，**不能用于接受细节、高亮或正式 SH 3 画质**。正式候选仍使用完整预算，默认至少 30,000 步。

真实数据首次导出遇到最大渲染差异 `1.457e-4`。逐项核验表明：位置、尺度、透明度和全部 SH 参数逐位相同；归一化四元数差异 `1.79e-7`，渲染 RMS `7.98e-8`，99.9% 分位误差 `5.96e-8`。检查现同时要求参数不变量、RMS ≤ `1e-6` 和最大差异低于四分之一 8-bit 灰阶，避免仅由浮点归一化引起误报。详细测量保存在 `export-diagnostic.json`。

恢复后的资源记录只包含恢复导出与评估；原 100 步首次执行未保留完整累计计时，不能把约 38 秒恢复耗时当成训练总耗时。新检查点已补充累计训练计时。
