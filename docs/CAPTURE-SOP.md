# 古建室内 360 采集 SOP（表盘走位法）

面向 Insta360 等全景视频机的室内/古建场景采集。目标是降低运动模糊、提高多视角交叉定位能力，从数据侧减少 3DGS 杂云（floater）。算法侧配合 Bilateral Grid 匀光与 Sparse Depth 深度锚（见 `train --backend gsplat` 默认开关）。本文是 [当前工作手册](CURRENT-WORKFLOW.md) 的采集补充，不替代其软件命令。

经验来源：知天下 AI《室内场景 3DGS 消除杂云的技术讲解》（BV1siXrBsE2t）及 B 站 3DGS 采集教程共性结论，已适配单机 360 路径。

## 1. 设备与曝光

| 项 | 建议 | 原因 |
| --- | --- | --- |
| 机身 | Insta360 X5/X6 等双鱼眼全景机 | 单机一次覆盖天/地/墙，视场等价多机位倾角 |
| 快门 | 尽量 ≥ 1/500 s（室内开手动/专业模式；不足则提 ISO） | 运动模糊会毁掉交叉定位，重建漂浮 |
| 帧率 | 原片可 30/60 fps；流水线 schema 6 按 1 fps 抽全景 | 重叠靠路径与匀速，不靠堆帧 |
| 镜头 | 使用超广角/默认全景拼接结果 | 广视场利于不同位置交叉定位 |
| 白平衡 | 同一次 Capture 内锁定 | 剧烈 AWB 变化加大光度残差，Bilateral Grid 只能补偿一部分 |
| 高光 | 避免正对窗户/射灯长时间过曝 | 饱和像素无信息，形成弱观测区 |

## 2. 表盘走位法（室内单间 / 院落堂屋）

把房间中心当作表盘中心，相机是沿表盘运动的针尖。**四阶段按序完成**，每阶段约 1 m/s 匀速，**转弯减速**，保证相邻帧有充足重叠。

### 阶段 A — 向心环绕（定空间框架）

- 对准房间中心，在 **低 / 中（手持常见高度）/ 高** 三个高度各做一圈环绕。
- 古建挑高大时，增加一层「半高」环绕梁架下方。
- 目的：先钉住地面、天花与四角的全局几何。

### 阶段 B — 井字路线（补深处）

- 在室内走 **「井」字**：两横两纵，覆盖前后进深与左右开间。
- 走廊/过道：沿轴线一来一回，再贴墙一来一回。
- 目的：补全 A 阶段环绕够不到的深处、隔断与门洞。

### 阶段 C — 离心环绕（扫墙面细节）

- **背对中心**，沿墙内侧再绕一圈或走一圈「贴墙回」。
- 对窗棂、柱础、彩画、砖雕等精细面放慢速度。
- 目的：正对墙面的观测能约束纯色墙体，减少远处平面被扩增错判成团状杂云。

### 阶段 D — 细节补拍（文字与铭刻）

- 匾额、对联、碑刻、题记：**多角度、慢速掠过**，至少斜射 + 正对各一遍。
- 短小摆件/斗拱：高、低两个高度各环绕一次。
- 目的：文字需要交叉视角才能锐利；只经过一次会糊成色块。

### 与流水线衔接

1. 一次连续、空间连续的走完记作一个 **Scene**；同文件不同选段用不同 **Capture ID**（见手册 §2）。
2. 正式对照优先选 **最早通过 QA 的连续 30 秒**；全片 Capture 可建，但不要立刻全量训练。
3. 薄弱区间依赖 schema 6 的局部 2 fps 补抽（最多一次）；补抽不能挽救大面积运动模糊或缺失墙面。
4. 算法默认：`train --backend gsplat` 启用 Bilateral Grid 与 Sparse Depth；关闭用 `--no-use-bilateral-grid` / `--no-use-sparse-depth`。Postshot 仍按其 `photo-comp` 设置。

## 3. 质量自检（拍完先看，再进 RealityScan）

- [ ] 全程无奔跑/急停；转弯处无整段拖影。
- [ ] 地面、天花、四角均有非单一角度覆盖。
- [ ] 深处隔断在相邻帧中至少两次从不同方向出现。
- [ ] 匾额对联可读，且不只出现在某一侧逆光帧。
- [ ] 人物尽量少；必须入镜时勿在同一墙面长时间停留。
- [ ] 同一 Capture 内曝光/白平衡基本稳定。

未满足则补拍对应阶段，而不是指望训练超参「修好」数据缺陷。
